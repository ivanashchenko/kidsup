# Интеграция KidsUP с API hh.ru

Выгрузка откликов на вакансии, анализ кандидатов и переписка с ними
через официальный API hh.ru (`https://api.hh.ru`).

---

## Что работает уже сейчас, без приложения на dev.hh.ru

Без токена API hh отдаёт только справочники — проверено запросами:

| Эндпоинт | Без токена |
|---|---|
| `/dictionaries`, `/areas`, `/industries`, `/professional_roles`, `/metro`, `/languages` | 200 OK |
| `/vacancies`, `/employers`, `/resumes`, `/negotiations`, `/me` | 403 forbidden |

То есть ни откликов, ни резюме, ни переписки без приложения получить нельзя —
даже свои собственные. Зато можно работать по резюме, выгруженным из кабинета
hh вручную (в интерфейсе резюме кандидата сохраняется в PDF):

```bash
pip install -r hh/requirements.txt
export ANTHROPIC_API_KEY=...

# сложите PDF-резюме в папку и запустите разбор по профилю вакансии
python3 -m hh screen ~/Downloads/otkliki --profile hh/profiles/teacher.md \
    --title "Воспитатель" --out otkliki.md

# письмо конкретному кандидату — скопировать и отправить руками в hh
python3 -m hh letter ~/Downloads/otkliki/ivanova.pdf --intent invite \
    --note "вт/чт после 15:00"
```

`screen` и `letter` не обращаются к hh вообще: PDF уходит в модель напрямую,
разбирать его чем-то ещё не нужно. Оценка и формат отчёта — те же, что потом
будут работать автоматически через API.

Ещё что стоит сделать, пока идёт модерация:
- отредактировать `hh/profiles/teacher.md` под реальные требования и завести
  отдельный профиль на каждую вакансию;
- прогнать `screen` на десятке уже полученных откликов и проверить, совпадают ли
  оценки с вашим мнением — промпт правится в `hh/analyze.py` (константа `SYSTEM`).

## Шаг 1. Зарегистрировать приложение на dev.hh.ru

Без приложения API не отдаёт ничего: сейчас даже поиск вакансий отвечает
`403 forbidden` без токена. Регистрация — самая долгая часть, поэтому начните с неё.

1. Откройте <https://dev.hh.ru/admin> и войдите под аккаунтом hh.ru.
   Удобнее сразу под тем аккаунтом менеджера, у которого есть доступ к откликам KidsUP.
2. Нажмите «Добавить приложение» и заполните форму:
   - **Название** — например, `KidsUP HR`.
   - **Описание** — коротко и по делу, это читает модератор hh. Например:
     «Внутренний инструмент центра развития детей KidsUP: выгрузка откликов на
     собственные вакансии, помощь HR в оценке резюме и ответах кандидатам.
     Публичного доступа нет, используется одним работодателем».
   - **Redirect URI** — `http://localhost:8765/callback` (значение по умолчанию в скрипте).
     Если hh не примет `localhost`, укажите адрес на вашем домене
     (например, `https://kidsup.example/oauth`) и пропишите его в `HH_REDIRECT_URI`.
   - **Контактный email** — на него hh пишет по вопросам модерации.
3. Отправьте на проверку. Приложение проходит модерацию hh — срок они не публикуют,
   на практике это несколько рабочих дней. Если тишина — напишите на api@hh.ru,
   указав название приложения и сценарий использования.
4. После одобрения в личном кабинете появятся **client_id** и **client_secret**.

Пока идёт модерация, всё остальное можно подготовить — код уже готов.

## Шаг 2. Настроить окружение

```bash
cp hh/.env.example .env      # .env уже в .gitignore
# заполните HH_CLIENT_ID, HH_CLIENT_SECRET, HH_APP_EMAIL
set -a; . ./.env; set +a
```

`HH_APP_EMAIL` обязателен: hh требует заголовок `HH-User-Agent` с названием
приложения и контактной почтой, иначе отвечает `bad_user_agent: blacklisted`.

## Шаг 3. Войти и проверить доступ

```bash
python3 -m hh login        # откроет страницу hh, попросит подтвердить доступ
python3 -m hh me           # покажет аккаунт и employer.id
python3 -m hh vacancies    # активные вакансии и счётчики откликов
```

Токен сохраняется в `~/.kidsup/hh_token.json` (права 600) и продлевается
автоматически по `refresh_token`.

## Шаг 4. Работа с откликами

```bash
# список откликов
python3 -m hh responses --vacancy 12345678 --only-new

# анализ откликов по профилю вакансии (нужен ANTHROPIC_API_KEY)
pip install -r hh/requirements.txt
python3 -m hh analyze --vacancy 12345678 --profile hh/profiles/teacher.md --out otkliki.md

# переписка по конкретному отклику
python3 -m hh chat 987654321

# черновик ответа — только печатается, никуда не уходит
python3 -m hh draft 987654321 --intent invite --note "вт/чт после 15:00"

# отправка: показывает текст и спрашивает подтверждение
python3 -m hh draft 987654321 --intent invite | python3 -m hh reply 987654321
```

`reply` без `--yes` всегда показывает текст и ждёт подтверждения — по умолчанию
ни одно сообщение не уходит кандидату автоматически. Если сообщение сгенерировано
моделью, добавляйте `--automated`: hh помечает такие сообщения флагом `is_automated`.

## Профили вакансий

`hh/profiles/*.md` — требования к кандидату в свободной форме, на их основе
строится оценка. `teacher.md` — пример для воспитателя/педагога; скопируйте
и поправьте под конкретную вакансию.

## Что использует интеграция

| Задача | Метод API |
|---|---|
| Авторизация | `https://hh.ru/oauth/authorize` → `POST /token` (authorization_code + PKCE) |
| Текущий аккаунт | `GET /me` |
| Вакансии компании | `GET /employers/{id}/vacancies/active` |
| Отклики по вакансии | `GET /negotiations/response?vacancy_id=...` |
| Один отклик | `GET /negotiations/{id}` |
| Резюме кандидата | `GET /resumes/{id}` |
| Чтение переписки | `GET /common/chats/{chat_id}/messages` |
| Отправка сообщения | `POST /common/chats/{chat_id}/messages` |

Старые методы `/negotiations/{nid}/messages` помечены в документации hh как
устаревшие — используются только как запасной вариант, если у отклика нет `chat_id`.

## Ограничения, о которых стоит знать

- Полный просмотр резюме с контактами может требовать платных услуг hh.
  Доступность проверяется методом
  `GET /employers/{id}/managers/{manager_id}/method_access`.
- Токен привязан к конкретному менеджеру: отклики видны те же, что и ему в интерфейсе.
- `refresh_token` одноразовый — после обновления сохраняется новая пара токенов.
- При компрометации токена его нужно инвалидировать (`DELETE /token`) и войти заново.
