# KidsUp Analytics

Веб-приложение для выгрузки и анализа данных из CRM **МойКласс**
([app.moyklass.com](https://app.moyklass.com/)).

Что умеет:

- **Выгрузка** всей базы через официальный API МойКласс в локальную базу
  (SQLite): ученики, заявки, платежи, счета, группы, курсы, филиалы,
  сотрудники, абонементы, занятия и посещаемость. Полные ответы API
  сохраняются как есть (JSON) — ни одно поле не теряется.
- **Аналитика на дашборде**: выручка и списания по месяцам, новые ученики,
  посещаемость, должники, заполненность и посещаемость групп, самые
  активные ученики.
- **Экспорт**: CSV (открывается в Excel) по ученикам, платежам, занятиям и
  посещаемости + выгрузка «сырых» JSON по каждой таблице.

## Быстрый старт

Нужен Python 3.10+.

```bash
pip install -r requirements.txt
uvicorn app.main:app --host 127.0.0.1 --port 8000
```

Откройте http://127.0.0.1:8000

1. Зайдите в **Настройки** и вставьте API-ключ МойКласс
   (создаётся в CRM: *Настройки → API*,
   https://app.moyklass.com/settings/settings/api).
2. Нажмите **«Проверить подключение»** — приложение авторизуется и покажет
   название вашей компании.
3. Нажмите **«Синхронизировать»** — данные выгрузятся в локальную базу
   (первая выгрузка может занять несколько минут, прогресс виден на экране).
4. Смотрите дашборд, фильтруйте учеников и платежи, скачивайте CSV.

### Демо-режим (без API-ключа)

Чтобы посмотреть интерфейс на тестовых данных:

```bash
python seed_demo.py
uvicorn app.main:app --port 8000
```

## Настройки (переменные окружения)

| Переменная | Назначение | По умолчанию |
|---|---|---|
| `MOYKLASS_API_KEY` | API-ключ (вместо ввода в интерфейсе) | — |
| `HISTORY_MONTHS` | Глубина выгрузки платежей и занятий, месяцев | 24 |
| `MOYKLASS_RPS` | Ограничение запросов к API в секунду | 4 |
| `APP_PASSWORD` | Если задан — вход по паролю (HTTP Basic) | выкл. |
| `APP_USER` | Логин для HTTP Basic | admin |
| `KIDSUP_DATA_DIR` | Каталог для базы данных | `./data` |

## Важно про безопасность

- База данных (`data/kidsup.db`) содержит персональные данные ваших
  клиентов — не выкладывайте её и не коммитьте в git (каталог `data/` уже
  в `.gitignore`).
- Если запускаете приложение на сервере, доступном из интернета,
  обязательно задайте `APP_PASSWORD` и используйте HTTPS (например, за
  nginx/caddy).
- API-ключ даёт полный доступ к вашей CRM — храните его как пароль.

## Как это устроено

```
app/
├── main.py            — веб-приложение (FastAPI): страницы, API, экспорт CSV/JSON
├── moyklass_client.py — клиент API МойКласс (токен, пагинация, повторы, лимит запросов)
├── sync.py            — фоновая синхронизация с прогрессом
├── db.py              — схема SQLite и сохранение сущностей
├── analytics.py       — SQL-запросы для метрик и графиков
├── templates/         — страницы (Jinja2)
└── static/            — стили и лёгкая библиотека SVG-графиков (без CDN)
```

Синхронизация идемпотентна: записи обновляются по `id`, повторный запуск
безопасен. Типы операций в платежах МойКласс: `income` — поступление денег,
`debit` — списание за занятия (признанная выручка), `refund` — возврат.
