# KidsUP — сайт центра развития детей и детского сада

Статический сайт центра развития детей и частного детского сада **KidsUP**
(Москва, б-р Маршала Рокоссовского, 6 к1В, м. Бульвар Рокоссовского).

## Структура

- `index.html` — главная страница: направления занятий, преимущества, отзывы, форма заявки, контакты
- `kindergarten.html` — английский (билингвальный) детский сад
- `schedule.html` — расписание, график работы и цены
- `css/style.css` — все стили (адаптивная вёрстка, мобильное меню)
- `js/main.js` — мобильное меню и обработка формы заявки

## Запуск

Сайт полностью статический — достаточно открыть `index.html` в браузере
или поднять любой статический сервер:

```bash
python3 -m http.server 8000
# затем открыть http://localhost:8000
```

## Примечание

Сайт воссоздан по общедоступным данным о центре (услуги, цены, адрес,
график работы). Иллюстрации — SVG-заглушки: замените их на реальные
фотографии центра. Форма заявки работает в демо-режиме — подключите свой
бэкенд или CRM в `js/main.js`.
