Подключение модели: пошагово

Что это даёт: разбор задач и переписок начнёт понимать смысл, а не искать слова. Сегодня «заявка с сайта» уехала к вам из-за слова «сайт», а «договорились» сработало как «договор» — такие ошибки исчезнут.

Почему нельзя просто вписать ключ. Наш сервер стоит в России, и api.anthropic.com отвечает ему 403 по региону. Нужен посредник за пределами страны — маленькая программа на Cloudflare, которая принимает запрос от нас и передаёт дальше. Она бесплатна: 100 000 запросов в сутки, нам нужно около сотни.
Часть 1 · ключ

Получить ключ Anthropic

1
Откройте console.anthropic.com

Войдите или зарегистрируйтесь. Это отдельный кабинет для API, не тот, где вы общаетесь со мной в чате.

2
Пополните баланс

Раздел Billing → добавить карту → пополнить. Для наших объёмов хватит 10–20 долларов на несколько месяцев: разбор одной задачи стоит доли цента.

3
Создайте ключ

Раздел API Keys → Create Key → назовите «kidsup-server». Ключ показывается один раз и начинается на sk-ant-. Скопируйте его — понадобится в части 3.

Ключ — это доступ к вашим деньгам. Не пересылайте его в мессенджерах и не показывайте на экране при демонстрациях. Если утёк — в том же разделе кнопка удалить, и создаёте новый.
Часть 2 · прокси

Поднять воркер на Cloudflare

4
Зарегистрируйтесь на dash.cloudflare.com

Бесплатный аккаунт, карта не нужна. Домен подключать не требуется.

5
Создайте воркер

В меню слева Compute → Workers & Pages → Create → Start with Hello World! → назовите kidsup-anthropic → Deploy.

6
Замените код

Нажмите Edit code. Выделите всё в редакторе и вставьте содержимое файла deploy/anthropic-proxy-worker.js из нашего репозитория — он же приложен ниже. Нажмите Deploy.

7
Задайте секрет

Вернитесь в настройки воркера: Settings → Variables and Secrets → Add → тип Secret, имя SHARED_SECRET, значение — любая длинная случайная строка, например kidsup-2026-jH7xQ2mP9vL4. Сохраните и запомните её: без этого секрета воркер отвечает «forbidden», и это правильно — иначе им пользовались бы посторонние.

8
Запишите адрес

На главной странице воркера будет ссылка вида https://kidsup-anthropic.ваш-логин.workers.dev. Это и есть адрес прокси.

Проверка, что воркер жив. Откройте в браузере адрес воркера с добавленным /__ping. Должно ответить {"error":"forbidden"} — это нормально и означает, что воркер работает и требует секрет. Полная проверка будет на шаге 10.
Часть 3 · включение

Прописать в системе

9
Передайте мне три значения

Ключ, адрес воркера и секрет. Я впишу их в настройки сервера — они хранятся в базе, а не в коде, и в репозиторий не попадают.

10
Проверяю связь

У нас есть проверка assistant.probe(): она стучится через прокси и говорит, дошло ли. Ответ 401 authentication_error означает «регион в порядке, дело только в ключе», ответ 200 — всё готово.

Что изменится

Сторож начнёт понимать, а не искать слова

  • Задачи попадут к тому, кто их делает. Сейчас маршрут выбирается по словам, и на границе он врёт. Модель читает задачу целиком и отвечает на вопрос «что здесь надо сделать и кто это делает».
  • Спорные задачи перестанут ждать меня. Сейчас сторож откладывает их до моего прихода. С моделью он разберёт их сам, в 8 утра и в 20 вечера.
  • Разбор переписок станет точнее. Намерение клиента — запись, перенос, отказ, вопрос о цене — определяется смыслом, а не набором слов.
  • Подсказки для звонка будут собираться под конкретного человека, а не по шаблону под сегмент.
Что не изменится. Модель не получит права на изменение данных сама по себе: она подсказывает решение, а применяют его те же проверенные функции с теми же предохранителями. Инварианты остаются — задача с деньгами не исчезает, свежий итог разговора не затирается старым планом обзвона.
Приложение

Код воркера

Тот же файл лежит в репозитории: deploy/anthropic-proxy-worker.js. Ключ Anthropic в нём не хранится — он проходит транзитом внутри защищённого соединения, воркер его не читает и не пишет в логи.

const UPSTREAM = "https://api.anthropic.com";

const PASS_THROUGH = [
  "x-api-key", "authorization", "anthropic-version",
  "anthropic-beta", "content-type", "accept",
];

export default {
  async fetch(request, env) {
    const expected = env.SHARED_SECRET;
    if (!expected) {
      return json({ error: "SHARED_SECRET не задан" }, 500);
    }
    if (request.headers.get("x-kidsup-auth") !== expected) {
      return json({ error: "forbidden" }, 403);
    }

    const url = new URL(request.url);
    if (url.pathname === "/__ping") {
      return json({ ok: true, upstream: UPSTREAM });
    }

    const headers = new Headers();
    for (const name of PASS_THROUGH) {
      const value = request.headers.get(name);
      if (value) headers.set(name, value);
    }

    let upstreamResponse;
    try {
      upstreamResponse = await fetch(UPSTREAM + url.pathname + url.search, {
        method: request.method,
        headers,
        body: ["GET", "HEAD"].includes(request.method) ? undefined : request.body,
      });
    } catch (err) {
      return json({ error: "upstream_unreachable", detail: String(err) }, 502);
    }

    const out = new Headers(upstreamResponse.headers);
    out.delete("content-encoding");
    out.delete("content-length");
    return new Response(upstreamResponse.body, {
      status: upstreamResponse.status,
      headers: out,
    });
  },
};

function json(body, status) {
  return new Response(JSON.stringify(body), {
    status,
    headers: { "content-type": "application/json; charset=utf-8" },
  });
}
