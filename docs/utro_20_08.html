Как считаем записи с сегодняшнего дня. Две цифры рядом: детей и записей. Один ребёнок на логопеде два раза в неделю — это один ребёнок и две записи. Ребёнок на двух предметах — тоже один ребёнок, две записи. Заполнение групп считаем по записям (места), результат работы — по детям.
