Лестница входа (как продаём)

  • Кружки: бесплатное пробное → покупка в день пробного = −15% на первый абонемент (окно выгоды 24 часа) → абонемент помесячно.
  • Сад/нулевой: экскурсия → пробная неделя → покупка месяца в течение 3 дней = зачёт стоимости недели.
  • Всем: оплата сентября до 30.08 — по ценам прошлого года (с новыми скидками не суммируется).
  • Каждая запись = резюме в WhatsApp + напоминание накануне с вопросом «Вы придёте?» + подготовленный педагог, который после пробного лично провожает родителя к стойке.
