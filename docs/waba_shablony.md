Общая причина: мы просили разрешение на **рассылку предложения**, а не на
сервисное сообщение. Новый профиль эту причину не убирает — те же тексты
в новом профиле отклонят так же.

## Что проходит модерацию

Meta пропускает шаблоны, которые отвечают на действие клиента: он записался,
он пришёл, он попросил. Ниже три текста под наши реальные поводы. Переменные
подписаны, чтобы было понятно, что подставлять.

```
Если планы изменятся — напишите в этот чат, перенесём.
```

## Правила, которые стоит держать в голове

- Никаких цен, скидок и слов «акция», «успейте», «последние места» —
  это переводит шаблон в marketing и режет шансы.
- Переменная не должна быть всем телом сообщения.
- Первое сообщение человеку, который нам не писал, — только по шаблону;
  дальше 24 часа можно переписываться свободно.
- Заводятся шаблоны руками в кабинете Wazzup: API их только читает.
