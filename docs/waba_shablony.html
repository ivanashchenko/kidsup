Почему отклонили все версии 1–5 (integrity)
  1. Один и тот же текст подавался 3–4 раза с новым суффиксом (_3, _4, _v2_2). Повторную подачу почти того же текста Meta считает попыткой обойти модерацию и режет автоматически, репутация номера падает.
  2. Длинный список предложений с днями и часами читается как рекламная рассылка. Wazzup советует то же: убрать список групп.
  3. «Ваш ребёнок ({{1}})» + возраст + время + адрес: текст про детей с именем ребёнка в переменной цепляет фильтр детской безопасности. Самая вероятная причина именно «integrity».
  4. Даты 29–31 августа уже прошли: на 4 сентября шаблон устарел, а устаревшее обещание для Meta «misleading».
  5. Номер новый, бизнес не верифицирован, проверка строже. Апелляция по старым текстам смысла не имеет: причина не названа, тексты всё равно устарели.
Порядок подачи
  1. Удалить в кабинете Wazzup все версии nabor_1_3_goda … nabor_bez_vozrasta и их копии, а также prazdnik_dod_nou.
  2. Подать один маркетинговый шаблон: nabor_korotkiy. Больше ничего одновременно. Ответ обычно за 1–60 минут, редко до суток.
  3. Отклонили — подать следующий по списку (без переменных → вопрос → заявка). Один и тот же текст второй раз не подавать.
  4. Параллельно можно подать сервисные шаблоны (категория Utility): они про конкретную запись и проходят почти всегда, а нам они нужны для подтверждений и напоминаний.
  5. Когда первый маркетинговый одобрен, ничего делать не нужно: сервер проверяет статусы каждые 5 минут и включает рассылку по базе. Полные тексты про группы по возрастам уходят уже обычным сообщением в ответ на «Да, расскажите».
