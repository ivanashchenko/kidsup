# Ежедневный контроль оплат (проект, 05.10.2026)

Цель: каждое утро видеть, что вчерашние деньги дошли туда, куда записаны, и что
никто не учится бесплатно и не продаёт дешевле прайса без решения владельца.

## Проверки (утро, 08:30, за вчера; итог владельцу одним сообщением, пункты — Лизе/Лене)
A. Деньги ↔ записи
 1. Терминал: сумма оплат «карта» в МК за день = реестр банка (D+1). Расхождение > 100 ₽ — поимённо.
 2. СБП/онлайн: каждая операция банка = оплата в МК (поштучно). Лишняя операция = не внесённая оплата.
 3. Наличные: каждая оплата «нал» в МК есть в тетради (фото за день) и имеет чек КОМТЕТ.
    Нал без тетради = деньги не дошли до кассы. Нал в МК, а по банку карта = путаница типов.
 4. Маткапитал: поступление ОСФР на счёт Буракова → перевод на KidsUP → приход «перевод на счёт» в МК
    на баланс того же ребёнка той же суммой → абонемент со списанием с баланса.
 5. Возвраты: возврат в МК → баланс 0 и абонемент закрыт; сумма = перевод «Возврат KidsUP» с личного счёта (ZenMoney).
B. Абонементы и цены
 6. Цена абонемента ниже прайса (за занятие) без скидочной причины; скидка > 15 %; ручная цена; абонемент на 1–200 ₽.
 7. −15 % «за пробное» не новому клиенту (была оплата до 20.08).
 8. Дубли абонементов на один месяц; абонемент удалён после оплаты (история действий).
 9. Абонемент не оплачен, а ребёнок уже ходил (nonPayedLessons, «проведено в долг»).
 10. Абонемент сотруднику/родне сотрудника (фамилии совпадают с персоналом) — отдельной строкой владельцу.
C. Посещения
 11. Ребёнок был на занятии, оплаченного абонемента на этот курс и дату нет (по lessonRecords).
 12. Занятие «проведено» без одного присутствующего, педагог получает за занятие — список по педагогам.
 13. Отметка «был» ребёнку, которого не было (сверка с отчётом педагога в «KidsUP Team» и, в споре, с камерой ресепшена).
D. История действий МК
 14. Удаления платежей/абонементов/записей, правки задним числом, входы вне смены и сотрудников, которых нет в графике.
E. Касса
 15. Остаток по тетради = остаток вчера + приходы − расходы − изъятия; расходы — только с чеком; изъятия — с подписью владельца.
 16. Раз в неделю владелец пересчитывает наличные в кассе и ставит подпись в тетради; расхождение с п.15 — сразу.

## Правила, без которых контроль не работает (решения владельца)
- Все наличные — через КОМТЕТ (чек родителю), иначе п.3 ловит только половину.
- Один тип платежа в МК на один способ оплаты: Нал · Карта (терминал) · СБП · Онлайн-ссылка · Перевод на счёт (МК) · Возврат с личного счёта.
- Скидки только из списка (−15 % новым в день пробного, −10 % второй предмет/ребёнок/многодетные), иное — только с пометкой «по согласованию с Б.И.».
- Абонемент создаётся до первого занятия месяца; «проведено в долг» допустимо не больше 2 занятий.
