Архив страниц

Страницы разовых кампаний и старые экраны. Данные и тексты на них могут быть устаревшими. В меню и на рабочих страницах их больше нет, по адресу они открываются. Список видит только владелец.

    {% for adres, nazvanie, chto, pochemu in arhiv %}
  • {{ nazvanie }}{{ adres }}

    {{ chto }}

    Почему в архиве: {{ pochemu }}

    • {% endfor %}

Переезжают на другие страницы

На каждой из этих страниц осталось то, чего на новой пока нет. Пока содержимое не перенесено, они открываются по адресу; в меню их нет.

    {% for adres, nazvanie, kuda, kuda_adres, ostalos in pereezd %}
  • {{ nazvanie }}{{ adres }}

    Переезжает на страницу «{{ kuda }}».

    Что там осталось: {{ ostalos }}

    • {% endfor %}

Старые документы лежат не здесь, а свёрнутым блоком «Архив» внизу своих списков: архив документов владельца · архив списков администраторов.
