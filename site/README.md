# Сайт kidsup.ru — что и куда выкладывать

Сборка: `python3 site/build_site.py` → `site/kidsup_site.html` (один самодостаточный файл,
логотипы и фото вшиты как data-URI, внешних зависимостей нет кроме Google Fonts).

## Файлы на хостинге

| Файл в репозитории | Адрес на сайте | Зачем |
|---|---|---|
| `site/kidsup_site.html` | `/` (index.html) | главная страница |
| `site/privacy.html` | `/privacy` | политика обработки персональных данных (ссылка из формы согласия — 152-ФЗ) |
| `site/oferta.html` | `/o` | договор-оферта (ссылка из футера) |
| `site/assets/og.jpg` | `/og.jpg` | превью ссылки в WhatsApp, Telegram, ВК |

Адреса `/privacy` и `/o` менять нельзя: на них стоят canonical, они же прописаны
в форме согласия и в футере главной. Если хостинг требует расширения — сделайте
редиректы `/privacy → /privacy.html` и `/o → /oferta.html`.

## Что перепроверить после выкладки

1. Форма заявки: отправить тестовую с реального телефона — заявка должна прийти
   в МойКласс и уведомлением дежурному (журнал: `app.kidsup.ru/api/public/leads`).
2. Расписание на странице подтянулось (секция «Расписание групп 2026/27»).
3. Яндекс.Метрика видит визит, Roistat подменяет номер телефона в шапке.
4. Ссылки `/privacy` и `/o` открываются, не 404.
